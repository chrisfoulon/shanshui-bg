# shanshui-bg

A slowly scrolling Chinese ink landscape for your desktop wallpaper (KDE Plasma) or as a website
background.

**The landscape is {Shan, Shui}\* by [Lingdong Huang](https://github.com/LingDong-)**
([original project](https://github.com/LingDong-/shan-shui-inf), MIT). This project only adapts it
to run as a background. See [CREDITS.md](CREDITS.md).

Status: early, nothing runs yet. See [STATUS.md](STATUS.md).
