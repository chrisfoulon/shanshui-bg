# Credits

This project is built on **{Shan, Shui}\*** by **Lingdong Huang**: a procedurally generated,
infinitely scrolling Chinese landscape painting, written in JavaScript.

- Original project: https://github.com/LingDong-/shan-shui-inf
- Live version: https://lingdong-.github.io/shan-shui-inf/
- Vendored here at commit `9f754d2b2e73495db7883d4d4055a7b0903b0454`, unmodified, in `upstream/`
- Licence: MIT, Copyright (c) 2018 Lingdong Huang. See `upstream/LICENSE`.

All the painting (the mountains, trees, water, mist, brush texture and the noise-based way
they are modelled) is Lingdong Huang's work. This project only repackages it so it can run as a
moving desktop wallpaper or a website background.

{Shan, Shui}\* was itself inspired by traditional Chinese landscape scrolls (*shan shui*
painting), as its README notes.

## How this project acknowledges the original
Our policy is to credit beyond what the licence requires, without getting in the way:
- Keep the MIT copyright and licence notice in every file derived from the original code.
- Name Lingdong Huang and link the original repo in our README, in the web component's source
  header, and in the KDE plugin's metadata (author/description fields).
- Web component: an optional, unobtrusive credit link (on by default, small, in a corner,
  low-contrast), which a site owner can turn off.
